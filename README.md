# amigurumien virkkausohjeita

Reposta löytyy virkkausohjeita, joita olen kehitellyt täysin itse tai soveltanut muiden ohjeista muokkaamalla tai
yhdistelemällä useampia ohjeita. Ohjeissa on viittaukset inspiraatiolähteisiin.

Voit vapaasti käyttää ohjeita miten vain haluat, mutta olisi arvostaisin viittausta tähän repoon ohjeen lähteenä.

>Jos ohje ei ole suomeksi, se noudattaa [US/amerikanenglannin lyhenteitä](https://www.katajala.net/marjut/neuleet/virkkaussanasto.shtml). 

# amigurumi crochet patterns

This repo contains amigurumi crochet patterns which I've created from scratch or based on someone else's work with
modifications or combining several patterns as a new one with reference to the original patterns.

Feel free to use the patterns the way you want, but as per common courtesy I'd appreciate reference to this repo if
you use the pattern.

> NOTE: The patterns use US English abbreviations.
